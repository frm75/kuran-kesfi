# Arama (/ara) Uygulama Planı

> **Ajan işçiler için:** ZORUNLU ALT BECERİ — bu planı görev görev uygulamak için
> `superpowers:subagent-driven-development` (önerilen) veya
> `superpowers:executing-plans` kullanın. Adımlar takip için onay kutusu
> (`- [ ]`) sözdizimindedir.

**Hedef:** `kurankesfi.tr` sitesine, build aşamasında üretilen parçalı ters indeks
üzerinde çalışan, tür sekmeleriyle sınıflandırılabilir bir arama sayfası (`/ara`)
eklemek; ayrıca `5/58`, `bakara 153`, `cüz 2`, `sayfa 23` gibi referansları ve
`yus.` gibi yarım sure adlarını anında çözmek.

**Mimari:** `scripts/build/lib/search.ts` PostgreSQL'den okuyup
`apps/web/public/data/search/` altına parçalı JSON yazar. `/ara` sayfası JS'siz de
dolu gelir (A-Z dizinler); JS varsa `apps/web/src/lib/search/` altındaki
bağımlılıksız motor shard'ları `fetch` ile çeker. Normalizasyon tek modülde durur ve
hem build hem istemci tarafından kullanılır.

**Teknoloji:** TypeScript, Astro 5 (statik export), Node `tsx` (test koşucusu),
PostgreSQL (yalnız build makinesinde). **Yeni bağımlılık yok** — arama kütüphanesi
kurulmaz.

**Spec:** `docs/superpowers/specs/2026-09-08-arama-design.md`

## Global Kısıtlar

Her görevin gereksinimlerine bunlar örtük olarak dahildir.

- **Yeni npm bağımlılığı eklenmez.** Arama motoru, normalizasyon ve test koşucusu
  mevcut araçlarla yazılır (`tsx`, TypeScript, Astro).
- **Test koşucusu vitest/jest DEĞİL.** Proje `tsx` ile çalışan düz smoke script'leri
  kullanır: dosya sonunda `check(label, ok)` yardımcısı, `passed` sayacı,
  `failures[]` dizisi, hata varsa `process.exitCode = 1`. Örnek:
  `apps/web/src/lib/__tests__/nav.smoke.ts`. Yeni testler
  `apps/web/package.json` içindeki `test:smoke` zincirine `&&` ile eklenir.
- **Kod ve tanımlayıcılar İngilizce, kullanıcıya görünen metin Türkçe**
  (`CLAUDE.md` İsimlendirme).
- **`import` yolları `.js` uzantılı** — proje ESM (`"type": "module"`);
  `../graf.js`, `./normalize.js` biçimi zorunlu, uzantısız import build'de düşer.
- **Web tarafı `~/lib/...` takma adını kullanır** (Astro `tsconfig` paths).
- **Statik JSON girintisiz yazılır** (`Emitter.write` `JSON.stringify(value)`
  kullanır); zaman damgası, rastgele değer veya sürüm numarası gömülmez —
  tekrarlanabilir build (plan §20.1).
- **CSP'de `'unsafe-inline'`, `'unsafe-eval'`, `wasm-unsafe-eval` AÇILMAZ.**
- **`/ara` dışındaki hiçbir sayfanın CSP'si değişmez.** Duman testi bunu doğrular.
- **Boyut bütçesi:** ilk arama < 60 KB gzip transfer; `public/data/search/` toplamı
  < 1 MB gzip (linter 1 MB'da uyarır, 1,5 MB'da build'i durdurur).
- **Commit mesajları Conventional Commits**, projedeki gibi Türkçe gövde:
  `feat(arama): ...`, `test(arama): ...`, `docs(arama): ...`.

```ts
/**
 * Arama normalizasyonu — TEK KAYNAK.
 *
 * ## Neden tek dosya
 *
 * Bu mantık iki yerde çalışır: build (scripts/build/lib/search.ts token'ları
 * ÜRETİR) ve tarayıcı (sorguyu token'a ÇEVİRİR). İki kopya olsaydı biri
 * değişince arama sessizce boş dönerdi — hata yok, sonuç yok. Bu yüzden build
 * script'i bu dosyayı doğrudan import eder, kendi kopyasını tutmaz.
 *
 * ## Bu dosya hiçbir şey IMPORT ETMEZ
 *
 * Ne veri katmanı, ne Astro. Böylece hem tarayıcı paketine hem Node build
 * script'ine bedelsiz girer.
 */

/** Token'ın indekse girmesi için gereken en az harf sayısı. */
export const MIN_TOKEN_LENGTH = 2;

/**
 * Durak kelimeler. Tek başına aranmaları anlamsız, indekste yer kaplarlar.
 * Tırnaklı tam ifade aramasında YİNE DE kullanılırlar — bu küme sadece
 * indekslemeyi ve serbest sorgu token'larını süzer.
 */
export const STOPWORDS: ReadonlySet<string> = new Set([
  "ve", "ile", "bir", "bu", "su", "o", "da", "de", "ki", "mi", "mu",
  "ise", "icin", "gibi", "ya", "veya", "ama", "fakat", "cok", "daha",
]);

/**
 * Türkçe'ye özel küçültme + ASCII katlama.
 *
 * TUZAK: düz `toLowerCase()` `I` harfini `i` yapar; Türkçe'de `I`'nın küçüğü
 * `ı`'dır. `IRMAK` -> `irmak` beklenirken `irmak` yerine yanlış token çıkardı
 * ve `ırmak` araması tutmazdı. `toLocaleLowerCase("tr")` bunu çözer, ASCII
 * katlaması ondan SONRA gelir.
 */
export function normalizeTr(input: string): string {
  return input
    .normalize("NFC")
    .toLocaleLowerCase("tr")
    .replace(/[âäà]/g, "a")
    .replace(/[îïì]/g, "i")
    .replace(/[ûùü]/g, "u")
    .replace(/[êëè]/g, "e")
    .replace(/[ôöò]/g, "o")
    .replace(/ı/g, "i")
    .replace(/ş/g, "s")
    .replace(/ğ/g, "g")
    .replace(/ç/g, "c")
    // Kesme, tire, nokta ve diğer noktalama BOŞLUĞA değil, HİÇE iner:
    // "En'âm" -> "enam" olmalı, "en am" değil.
    .replace(/['’`´.,;:!?()[\]{}"«»–—_/\\-]/g, "")
    .replace(/\s+/g, " ")
    .trim();
}

/*
 * Arapça karakter sınıfları.
 *
 * STRIP_CLASS_RE scripts/build/principle_candidates.ts:112'den BAYT DÜZEYİNDE
 * kopyalanmıştır. Aralığı fethatan (U+064B) ile bitirmek fatha, damma, kasra,
 * şedde, sükûn ve medde işaretlerini KAÇIRIR; kalıp eşleşmesi hata vermeden
 * sıfır sonuç döndürür. Elle yeniden yazılmamalıdır.
 */
const STRIP_CLASS_RE = /[ؐ-ًؚ-ٰٟۖ-ۭـ]/g;
const ALEF_CLASS_RE = /[آأإٱ]/g;
const HAMZA_ALEF_RE = /ءا/g;
const YA_MAKSURA_RE = /[ىی]/g;
const TA_MARBUTA_RE = /ة/g;

/**
 * Arapça normalizasyon.
 *
 * İndeks girdisi `verse.text_no_vowel` kolonudur; hareke zaten yoktur ama
 * hamzeli/medli elif (`أ`, `آ`) DURUR — `أيها`, `آمنوا`. Bu yüzden katlama
 * yine gerekir, yoksa `ايها` arayan `أيها` bulamaz.
 */
export function normalizeAr(input: string): string {
  return input
    .normalize("NFC")
    .replace(STRIP_CLASS_RE, "")
    .replace(ALEF_CLASS_RE, "ا")
    .replace(HAMZA_ALEF_RE, "ا")
    .replace(YA_MAKSURA_RE, "ي")
    .replace(TA_MARBUTA_RE, "ه")
    .replace(/\s+/g, " ")
    .trim();
}

const ARABIC_RANGE_RE = /[؀-ۿݐ-ݿ]/;

/** Sorgunun hangi ad alanında aranacağını belirler (bkz. query.ts). */
export function hasArabic(input: string): boolean {
  return ARABIC_RANGE_RE.test(input);
}

/** Normalize eder, boşluktan böler, kısa ve durak token'ları eler. */
export function tokenize(input: string, script: "tr" | "ar"): string[] {
  const normalized = script === "ar" ? normalizeAr(input) : normalizeTr(input);
  if (normalized === "") return [];
  return normalized
    .split(" ")
    .filter((t) => t.length >= MIN_TOKEN_LENGTH && !STOPWORDS.has(t));
}

/*
 * Türkçe ünsüz yumuşaması. ASCII katlama SONRASI hâline kurulur, çünkü
 * `softenFinal` normalize edilmiş token alır: `ç` orada zaten `c` olmuştur.
 *
 * `c` kendine eşlenir: `ç`->`c` katlaması yumuşak hâli zaten üretmiştir,
 * ikinci bir dönüşüm gerekmez ama tablo eksiksiz dursun diye yazılıdır.
 */
const SOFTEN: Readonly<Record<string, string>> = { p: "b", c: "c", t: "d", k: "g" };

/**
 * Sorgu token'ının yumuşamış hâli — `kitap` -> `kitab`, böylece `kitabı`
 * bulunur. İNDEKSE ek kayıt yazılmaz; bu yalnızca sorgu tarafında ikinci bir
 * ön ek denemesidir.
 *
 * @returns yumuşamış token, ya da yumuşama uygulanamıyorsa `null`
 */
export function softenFinal(token: string): string | null {
  if (token.length < MIN_TOKEN_LENGTH) return null;
  const last = token[token.length - 1] ?? "";
  const soft = SOFTEN[last];
  if (soft === undefined) return null;
  return token.slice(0, -1) + soft;
}
```

/**
 * Referans ayrıştırıcı — "5/58", "bakara 153", "cüz 2", "sayfa 23".
 *
 * Sorgu metin aramasından ÖNCE buradan geçer. Eşleşirse sonuçların başına
 * "Doğrudan git" kartı konur; metin sonuçları yine de altta listelenir, çünkü
 * "5" yazan biri hem Mâide suresini hem "5" geçen ayetleri arıyor olabilir.
 *
 * ## Neden sınır aşımı `null` değil
 *
 * "2/300" için boş sonuç dönmek kullanıcıya sitenin bozuk olduğunu
 * düşündürür. `outOfRange` kartı Bakara'nın 286 ayet olduğunu söyler ve sure
 * sayfasına bağlar.
 */

import { normalizeTr } from "./normalize.js";
import type { QuickAlias, QuickSurah } from "./types.js";

export interface ReferenceTables {
  surahs: readonly QuickSurah[];
  aliases: readonly QuickAlias[];
  /** juzStarts[n-1] = cüz n'in [sureId, ayetNo] başlangıcı. */
  juzStarts: readonly (readonly [number, number])[];
  /** pageStarts[n-1] = sayfa n'in [sureId, ayetNo] başlangıcı. */
  pageStarts: readonly (readonly [number, number])[];
}

export type ReferenceHit =
  | { kind: "verse"; surah: QuickSurah; verse: number; url: string }
  | { kind: "range"; surah: QuickSurah; from: number; to: number; url: string }
  | { kind: "surah"; surah: QuickSurah; url: string }
  | { kind: "juz"; juz: number; surah: QuickSurah; verse: number; url: string }
  | { kind: "page"; page: number; surah: QuickSurah; verse: number; url: string }
  | { kind: "outOfRange"; message: string; url: string };

const MAX_SURAH = 114;
const MAX_JUZ = 30;
const MAX_PAGE = 604;

/**
 * Sorguyu ayrıştırmaya hazır hâle getirir.
 *
 * `normalizeTr` noktalamayı HİÇE indirdiği için burada kullanılamaz:
 * "5/58" -> "558" olurdu. Bu yüzden ayıraçlar önce tek boşluğa çevrilir,
 * sonra kelimeler tek tek normalize edilir.
 */
function prepare(query: string): { words: string[]; raw: string } {
  const raw = query.trim();
  const spaced = raw
    .replace(/[/:.,;-]/g, " ")
    .replace(/\s+/g, " ")
    .trim();
  return { words: spaced === "" ? [] : spaced.split(" "), raw };
}

/** Sure adı veya eş adı → sure. Belirsizse (birden çok aday) `null`. */
function matchSurahName(word: string, tables: ReferenceTables): QuickSurah | null {
  const n = normalizeTr(word);
  if (n.length < 2) return null;

  const byId = new Map(tables.surahs.map((s) => [s.id, s]));
  const candidates = new Set<QuickSurah>();
  let exact: QuickSurah | null = null;

  for (const s of tables.surahs) {
    const name = normalizeTr(s.nameTr);
    if (name === n) exact = s;
    else if (name.startsWith(n)) candidates.add(s);
  }
  for (const a of tables.aliases) {
    const name = normalizeTr(a.name);
    const s = byId.get(a.surahId);
    if (s === undefined) continue;
    if (name === n) exact = exact ?? s;
    else if (name.startsWith(n)) candidates.add(s);
  }

  // Tam ad her zaman kazanır: "nur" yazan Nûr'u ister, Nûh'u değil.
  if (exact !== null) return exact;
  // Ön ek birden çok sureye düşüyorsa referans SAYILMAZ. "yu 4" Yûnus ve
  // Yûsuf arasında kalır; yanlış ayete göndermektense metin aramasına bırak.
  return candidates.size === 1 ? [...candidates][0] ?? null : null;
}

function surahById(id: number, tables: ReferenceTables): QuickSurah | null {
  return tables.surahs.find((s) => s.id === id) ?? null;
}

function verseHit(surah: QuickSurah, verse: number): ReferenceHit {
  if (verse < 1 || verse > surah.verseCount) {
    return {
      kind: "outOfRange",
      message: `${surah.nameTr} suresi ${String(surah.verseCount)} ayettir.`,
      url: `/${surah.slug}`,
    };
  }
  return { kind: "verse", surah, verse, url: `/${surah.slug}/${String(verse)}` };
}

/** "5. sure 58. ayet" ve "sure 5 ayet 58" — sözel biçim. */
function parseVerbose(words: string[], tables: ReferenceTables): ReferenceHit | null {
  const joined = words.map((w) => normalizeTr(w)).join(" ");
  const m = /^(?:sure\s+)?(\d+)\s+sure\s+(\d+)\s+ayet$|^sure\s+(\d+)\s+ayet\s+(\d+)$/.exec(joined);
  if (m === null) return null;
  const surahNo = Number(m[1] ?? m[3]);
  const verseNo = Number(m[2] ?? m[4]);
  const surah = surahById(surahNo, tables);
  if (surah === null) return null;
  return verseHit(surah, verseNo);
}

export function parseReference(query: string, tables: ReferenceTables): ReferenceHit | null {
  const { words, raw } = prepare(query);
  if (words.length === 0) return null;

  const verbose = parseVerbose(words, tables);
  if (verbose !== null) return verbose;

  const first = words[0] ?? "";
  const firstNorm = normalizeTr(first);

  // --- cüz / sayfa ---------------------------------------------------------
  // Hem "cüz 2" hem "2. cüz" — sıra iki türlü yazılıyor.
  const unitWord = ["cuz", "sayfa"].includes(firstNorm)
    ? firstNorm
    : words.length === 2 && ["cuz", "sayfa"].includes(normalizeTr(words[1] ?? ""))
      ? normalizeTr(words[1] ?? "")
      : null;

  if (unitWord !== null) {
    const numberWord = firstNorm === unitWord ? words[1] : words[0];
    const n = Number(numberWord);
    if (!Number.isInteger(n)) return null;
    const isJuz = unitWord === "cuz";
    const max = isJuz ? MAX_JUZ : MAX_PAGE;
    const label = isJuz ? "Cüz" : "Sayfa";
    if (n < 1 || n > max) {
      return {
        kind: "outOfRange",
        message: `${label} numarası 1 ile ${String(max)} arasında olmalı.`,
        url: isJuz ? "/sureler" : "/sureler",
      };
    }
    const table = isJuz ? tables.juzStarts : tables.pageStarts;
    const start = table[n - 1];
    if (start === undefined) return null;
    const surah = surahById(start[0], tables);
    if (surah === null) return null;
    const url = `/${surah.slug}/${String(start[1])}`;
    return isJuz
      ? { kind: "juz", juz: n, surah, verse: start[1], url }
      : { kind: "page", page: n, surah, verse: start[1], url };
  }

  // --- aralık: "2/153-160" · "bakara 153-160" ------------------------------
  // '-' YALNIZ ayet numarasından sonra aralık ayıracıdır; prepare() onu
  // boşluğa çevirdiği için ham metne bakılır.
  const rangeMatch = /^(\S+)[\s/:.]+(\d+)\s*-\s*(\d+)$/.exec(raw);
  if (rangeMatch !== null) {
    const head = rangeMatch[1] ?? "";
    const from = Number(rangeMatch[2]);
    const to = Number(rangeMatch[3]);
    const surah = /^\d+$/.test(head) ? surahById(Number(head), tables) : matchSurahName(head, tables);
    if (surah !== null && from >= 1 && to >= from) {
      if (to > surah.verseCount) {
        return {
          kind: "outOfRange",
          message: `${surah.nameTr} suresi ${String(surah.verseCount)} ayettir.`,
          url: `/${surah.slug}`,
        };
      }
      return { kind: "range", surah, from, to, url: `/${surah.slug}/${String(from)}` };
    }
  }

  // --- "sure ayet" iki parça ------------------------------------------------
  // "bakara suresi 153" üç kelime: ortadaki "suresi" atılır.
  const parts = words.filter((w) => normalizeTr(w) !== "suresi" && normalizeTr(w) !== "sure");

  if (parts.length === 2) {
    const head = parts[0] ?? "";
    const verse = Number(parts[1]);
    if (Number.isInteger(verse)) {
      const surah = /^\d+$/.test(head) ? surahById(Number(head), tables) : matchSurahName(head, tables);
      if (surah !== null) return verseHit(surah, verse);
    }
    return null;
  }

  // --- tek parça ------------------------------------------------------------
  if (parts.length === 1) {
    const only = parts[0] ?? "";
    if (/^\d+$/.test(only)) {
      const n = Number(only);
      if (n < 1 || n > MAX_SURAH) return null;
      const surah = surahById(n, tables);
      if (surah === null) return null;
      return { kind: "surah", surah, url: `/${surah.slug}` };
    }
  }

  return null;
}

/**
 * Sorgu TAMAMEN bir referanstan mı ibaret?
 *
 * Öyleyse Enter tuşu doğrudan ayete gider. "bakara sabır" için gitmez —
 * kullanıcı orada arama yapıyor.
 */
export function isPureReference(query: string): boolean {
  const { words } = prepare(query);
  if (words.length === 0 || words.length > 4) return false;
  const numeric = words.filter((w) => /^\d+$/.test(w)).length;
  const keywords = words.filter((w) =>
    ["sure", "suresi", "ayet", "cuz", "sayfa"].includes(normalizeTr(w)),
  ).length;
  // En az bir sayı olmalı ve sayı olmayan her kelime ya anahtar kelime ya da
  // tek bir sure adı olmalı.
  if (numeric === 0) return false;
  return numeric + keywords >= words.length - 1;
}

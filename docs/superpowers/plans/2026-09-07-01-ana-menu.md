# Ana Menü Yeniden Yapılandırma — Uygulama Planı (1/3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sitedeki 11 düz menü linkini Oku · Anla · Keşfet · Kaynaklar dörtlüsüne indirmek; alt sayfaları JS'siz açılır menü ve hub sayfalarıyla erişilebilir kılmak.

**Architecture:** Menü yapısı tek bir saf veri dosyasında (`nav.ts`) durur; şerit bileşeni, hub sayfaları, breadcrumb'lar ve sitemap aynı diziden beslenir. Açılır menü tamamen CSS'tir (`:hover` + `:focus-within`); dokunmatik genişlikte alt liste hiç basılmaz ve gezinme hub sayfasından sürer. Hiçbir sayfaya betik eklenmez, CSP'ye dokunulmaz.

**Tech Stack:** Astro 5 (statik export, `build.format: "file"`), TypeScript, elle yazılmış CSS (`global.css`), `tsx` ile çalışan duman testleri.

**Spec:** `docs/superpowers/specs/2026-09-07-menu-kavram-ilke-design.md` (Bölüm A)

## Global Constraints

- **JS eklenmez.** `infra/nginx/kurankesfi.tr.conf` içindeki `$kesif_csp` varsayılanı `default-src 'none'`. Bu plan CSP'yi değiştirmez ve hiçbir sayfaya `<script>` koymaz.
- **Tekrarlanabilir build** (plan §20.1): zaman damgası, rastgelelik, ortam değişkeni okuması yok.
- **Türkçe slug'lar aksansızdır:** `/kesfet`, `/oku`, `/anla` (mevcut `/kavramlar`, `/kissalar`, `/kok` kalıbı).
- **`aria-current="page"` sayfa başına en fazla bir kez** basılır.
- **Renk tek başına anlam taşımaz** — aktif bağlantı renk + alt çizgi ile işaretlenir (mevcut kural).
- Yorumlar ve kullanıcıya görünen metin **Türkçe**dir; kod kimlikleri İngilizce kalabilir.
- Çalıştırma kökü depo köküdür (`/opt/kuran`), paket yöneticisi **pnpm**.

/** Hub + çocuk yolları, menüdeki sırayla. Tekrar eden adres bir kez döner. */
export function allNavPaths(): string[] {
  const seen = new Set<string>();
  const out: string[] = [];
  for (const hub of NAV) {
    for (const href of [hub.href, ...hub.children.map((c) => c.href)]) {
      if (seen.has(href)) continue;
      seen.add(href);
      out.push(href);
    }
  }
  return out;
}

/**
 * Verilen yolun ait olduğu üst başlık.
 *
 * Hub'ın kendi adresi de, çocuklarının adresleri de aynı hub'ı döndürür.
 * Menüde olmayan bir yol (sure, ayet, kavram detayı) `null` döner — şerit o
 * zaman hiçbir başlığı aktif işaretlemez.
 */
export function findHub(path: string): NavHub | null {
  for (const hub of NAV) {
    if (hub.href === path) return hub;
    if (hub.children.some((c) => c.href === path)) return hub;
  }
  return null;
}
